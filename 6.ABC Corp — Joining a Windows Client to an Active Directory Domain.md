**Objective:** Join a Windows client PC to the `ABC.lab` Active Directory domain managed by `ABC-DC01`.

### Step 1: Open System Settings

Client PC पर **Settings → System → About** खोलें। यहाँ computer की system information दिखाई देगी। संबंधित settings में **Domain or workgroup** या **Advanced system settings** का विकल्प खोलें। Windows version के अनुसार navigation थोड़ा अलग हो सकता है।
![](../Attachments/Pasted%20image%2020261013091945.png)
### Step 2: Configure Computer Name and Domain
![](../Attachments/Pasted%20image%2020261013092104.png)

![](../Attachments/Pasted%20image%2020261013092357.png)
System Properties में **Computer Name → Change** पर क्लिक करें।

- **Computer name:** `ABC-CLIENT01`
    
- **Member of:** `Domain`
    
- **Domain:** `ABC.lab`
    

ध्यान दें: `ABC.lab` को **Computer Description** में नहीं, बल्कि `Member of → Domain` वाले field में दर्ज करना है।

### Step 3: Authenticate the Domain Join
![](../Attachments/Pasted%20image%2020261013092851.png)

![470](../Attachments/Pasted%20image%2020261013092937.png)

**OK** पर क्लिक करें। जब credentials माँगे जाएँ, तो ऐसा domain account दर्ज करें जिसके पास computer को domain में join करने की permission हो।

उदाहरण: `ABC\Administrator` — केवल तभी, जब यह account मौजूद हो और उसके पास आवश्यक permissions हों।

Windows Domain Controller से संपर्क करके domain join request को verify करेगा। सफल होने पर welcome message दिखाई देगा।

### Step 4: Restart the Client


Confirmation स्वीकार करें और client PC को restart करें, ताकि domain membership प्रभावी हो जाए।

### Step 5: Log In Using a Domain User
![](../Attachments/Pasted%20image%2020261013093536.png)
Restart के बाद login screen पर **Other user** चुनें और Active Directory में पहले से बनाए गए user की credentials दर्ज करें।

उदाहरण: `ABC\username`

![](../Attachments/Pasted%20image%2020261013094705.png)

यहाँ domain join करने वाला account और रोज़ाना login करने वाला domain user अलग-अलग हो सकते हैं।

### Step 6: Verify Domain Membership
Command Prompt या PowerShell खोलें और `systeminfo` कमांड चलाएँ। Output में **Domain** के सामने `ABC.lab` देखें। यदि यह domain name दिखाई देता है, तो आपका computer `ABC.lab` domain का member है।

### Local Administration vs Domain Administration

Windows में **Local Administration और Domain Administration दो अलग-अलग concepts हैं।** Local administration किसी specific computer को manage करने से संबंधित है, जबकि domain administration Active Directory domain के resources और policies को manage करने से संबंधित है। किसी user के पास कौन-से administrative privileges हैं, यह उसके account type के साथ-साथ उसे दिए गए permissions और group memberships पर निर्भर करता है। इसलिए केवल username में `Admin` होने से यह तय नहीं होता कि उसके पास कितने privileges हैं।

Domain से जुड़े computer पर Active Directory account से login करने का अर्थ यह नहीं है कि उस user को computer की हर system-level setting बदलने का अधिकार मिल गया है। उदाहरण के लिए, computer को domain से निकालकर Workgroup में ले जाना या उसकी domain membership बदलना एक administrative operation है। इसके लिए ऐसे credentials चाहिए जिनके पास उस operation को करने की अनुमति हो। सामान्यतः local administrator credentials इसका एक सीधा तरीका हैं; उचित permissions और configuration होने पर domain account भी यह operation कर सकता है।

### Windows में Local Account की पहचान

यहाँ Windows का एक महत्वपूर्ण mechanism समझना ज़रूरी है। जब computer पर Windows install किया जाता है, तब बनाया गया `labadmin` account उस specific computer का **local account** होता है। बाद में computer को Active Directory domain से join करने पर यह local account न तो domain account में बदलता है और न ही अपने आप समाप्त होता है।

अब computer पर local और domain—दोनों प्रकार के accounts उपलब्ध हो सकते हैं। इसलिए Windows में यह स्पष्ट करना उपयोगी होता है कि authentication किस account के माध्यम से करनी है। केवल `labadmin` लिखने के बजाय computer name के साथ `COMPUTERNAME\labadmin` लिखने से Windows को स्पष्ट हो जाता है कि local account इस्तेमाल करना है। इसमें computer name और username के बीच backslash (`\`) आता है।

### हमारी ABC Corp Lab में

हमारे lab में, यदि `ABC-CLIENT01` पर Windows installation के दौरान `labadmin` local account बनाया गया था, तो उस account से administrative authentication के लिए username इस format में दिया जा सकता है:

`ABC-CLIENT01\labadmin`

इसके बाद वही password इस्तेमाल होगा जो उस local account के लिए निर्धारित किया गया था। दूसरी ओर, `ABC\ITAdmin` Active Directory domain का account है। दोनों accounts की पहचान और permissions अलग-अलग हैं। सही account चुनना और उसके पास आवश्यक administrative rights होना—दोनों ज़रूरी हैं।
