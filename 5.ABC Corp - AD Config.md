

ABC Corp की Active Directory configuration पूरी हो चुकी है। अब हम अगले चरण में जा रहे हैं, जहाँ हमें directory को इस तरह व्यवस्थित करना है कि कंपनी के departments, users, computers और security groups को आसानी से manage किया जा सके।

सबसे पहले हमने Active Directory की default site का नाम बदलकर `ABC-HO` किया है। इसका उद्देश्य हमारी Head Office location को एक meaningful नाम देना है, ताकि आगे network topology और site configuration को समझते समय default नाम पर निर्भर न रहना पड़े। ध्यान रहे कि Site का नाम बदलने से Domain Name नहीं बदलता। ये दोनों Active Directory के अलग-अलग हिस्से हैं।

**Current Site Name:** `abc.lab`

अब site का नाम बदलने के बाद हमें ABC Corp की directory को व्यवस्थित करना है। हमारी कंपनी में अलग-अलग departments होंगे और हर department के अपने users होंगे। इसके अलावा, हमें client computers और security groups को भी अलग-अलग manage करना है।

इस lab में हमारे पास एक Windows Server 2025 और तीन client PCs हैं। इसलिए हम hierarchy को इतना व्यवस्थित रखेंगे कि वास्तविक कंपनी का structure represent हो सके, लेकिन अनावश्यक OUs और अतिरिक्त objects न बनाने पड़ें।

इसके लिए हम एक मुख्य Organizational Unit बनाएँगे, जिसका नाम `ABC-HO` होगा। इसके अंदर `Departments`, `Workstations` और `Security Groups` रखेंगे। Departments के अंदर HR, IT और Operations की अलग-अलग OUs होंगी।

OU बनाने के लिए हम **Server Manager → Tools → Active Directory Users and Computers** खोलेंगे। फिर अपने वर्तमान domain को expand करके उस पर right-click करेंगे और **New → Organizational Unit** से `ABC-HO` बनाएँगे।

हाँ `ABC.lab` हमारी पिछली project conversation में दर्ज domain name है। Screenshot लेते समय अपने server पर दिखाई देने वाला actual domain name चुनें। यदि current configuration में domain name अलग दिखाई देता है, तो उसी को note में दर्ज करें। Site का नाम `ABC-HO` होने का अर्थ यह नहीं है कि domain name भी `ABC-HO` से शुरू होना चाहिए।
अब हमारी directory structure तैयार होने के बाद हम इसमें sample employee accounts बनाएँगे। HR, IT और Operations के लिए एक-एक user बनाएँगे, ताकि हम देख सकें कि अलग-अलग departments के users को उनकी संबंधित OU में कैसे रखा जाता है।

हमारे planned sample usernames `hr.user`, `it.user` और `ops.user` हैं। इन्हें संबंधित departmental OU के अंदर create करेंगे। User creation के दौरान account name और password की settings current domain configuration के अनुसार रखेंगे। Password policies की विस्तृत configuration हम उसके संबंधित अगले चरण में करेंगे।

Users बनाने के बाद अगला कदम उन्हें security groups में व्यवस्थित करना है। इससे हमें हर user को अलग-अलग manage करने के बजाय department के अनुसार group membership manage करने की सुविधा मिलेगी।

हम `Security Groups` OU के अंदर `GG-HR`, `GG-IT`, `GG-Operations` और `GG-AllStaff` बनाएँगे। ये सभी Global Security Groups होंगे। इसके बाद हर departmental user को उसके संबंधित group और common group `GG-AllStaff` में add करेंगे।

अंत में हम Active Directory Users and Computers में पूरी configuration verify करेंगे। हम देखेंगे कि Site का नाम `abc.lab` है, `ABC-HO` के अंदर सही OU hierarchy मौजूद है, users सही departments में हैं और security groups के अंदर सही members जोड़े गए हैं। साथ ही, Domain Controllers OU को उसकी मौजूदा जगह पर ही रहने देंगे।
