### NetBIOS vs DNS — Why Both Names Exist in Active Directory

पुराने Windows networks में NetBIOS naming का उपयोग computers और network resources को छोटे, याद रखने योग्य names से पहचानने और access करने के लिए किया जाता था। छोटे LAN में यह उपयोगी था, लेकिन बड़े और geographically distributed networks में flat naming तथा broadcast-based discovery की limitations सामने आईं।

DNS ने **hierarchical naming और scalable name resolution** प्रदान किया। उदाहरण के लिए, अलग-अलग branches में `FILE01` नाम के servers को `file01.ahmedabad.abc.example` और `file01.mumbai.abc.example` जैसे FQDNs से अलग-अलग identify किया जा सकता है।

Active Directory ने DNS को domain naming और Domain Controller discovery का मुख्य आधार बनाया, लेकिन पुराने Windows logon conventions के साथ compatibility बनाए रखने के लिए NetBIOS domain name भी रखा। इसलिए एक ही AD domain के दो naming formats हो सकते हैं:

- **DNS domain name:** `abc.local`
    
- **NetBIOS domain name:** `ABC`
    

इस प्रकार, आज NetBIOS domain name मुख्यतः legacy compatibility के लिए मौजूद है; यह कोई अलग domain या अतिरिक्त server नहीं है।
